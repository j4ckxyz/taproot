# Changelog

## 0.1.0

First public release.

- Waterfall project canvas: cards, pills, milestones and text; sub-tasks spread out or listed; depth and branching limits per project.
- Deadlines with due-soon and overdue highlights, notes, tags, dates and custom fields.
- Spring motion: cards slide into place and push their neighbours; instant check-off.
- Right-click menu with every action, a selection bar, a `?` shortcut sheet and find (`/`).
- Live sync across tabs, devices and agents, with presence cursors and a live activity log.
- MCP server (Streamable HTTP) and REST API with OpenAPI docs; tokens are read-only unless allowed to write, and can be limited to projects.
- Exports: PNG, SVG, Excalidraw, Markdown, OPML, Mermaid, JSON. Imports: JSON, Markdown, OPML.
- Multi-user, preferences synced to your account, automatic gzipped backups (including before upgrades), and an in-app update notice.
